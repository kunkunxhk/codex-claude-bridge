# Windows 独立发行计划

目标：保留双向 MCP 的会话定位、请求去重和回复关联，将机器配置移至用户状态目录，交付可复制的源码 ZIP。

1. 搬运原有核心和回归测试，按 MIT 许可内置最小 peer adapter 闭包。
2. 先测试依赖发现、JSON/TOML 配置保留、卸载恢复与冲突保护，再实现安装生命周期。
3. 自动检测原生 Codex、Claude、Python；缺依赖明确退出，提供自定义路径参数。安装不处理账号登录。
4. 一键入口安装 npm 锁定依赖、备份配置、注册两端 stdio MCP。用户状态位于 LOCALAPPDATA；不绑定任何业务仓库。
5. 先在隔离配置目录验证安装/重装/卸载，再运行真实 MCP 协议和模型回复测试。
6. 生成白名单 ZIP，检查无用户数据、凭据、机器路径；保留第三方许可和兼容性说明。

卸载仅恢复本项目管理的两个配置项，遇到后续人为修改则拒绝覆盖。保留会话、回执、备份和源码。不会提交业务 Git。
